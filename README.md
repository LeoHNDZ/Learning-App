# Studio Learning App

An interactive educational application that teaches users how the [LeoHNDZ/studio](https://github.com/LeoHNDZ/studio) repository works and what each part of its code does.

## Features

### 🔍 Interactive Code Explorer
- Navigate through the studio repository structure
- View detailed explanations of each file's purpose
- Understand key features and technical details
- See code examples and related files

### 📚 Tutorial Section
- Step-by-step guides for key workflows
- Progressive learning with difficulty levels (beginner, intermediate, advanced)
- Interactive progress tracking
- Comprehensive explanations of complex concepts

### 🔎 Search Functionality
- Fast search across files, tutorials, and quiz questions
- Intelligent relevance scoring
- Category-based filtering
- Popular search suggestions

### 🏗️ Visual Architecture Diagrams
- Interactive system architecture visualization
- Clickable components with detailed information
- Data flow explanations
- Technology stack overview

### 🧠 Knowledge Quiz
- Test understanding with interactive quizzes
- Category-based questions (Architecture, Data Management, Algorithms, UI/UX)
- Detailed explanations for each answer
- Progress tracking and scoring

## What You'll Learn

The studio repository is a **Next.js-based TicketMaker application** that demonstrates:

- **Modern React Architecture**: Next.js 15 with App Router, React 18 hooks, TypeScript
- **Canvas-based Editing**: Interactive text positioning and styling
- **Smart Autocomplete System**: N-gram phrase extraction with exponential decay scoring
- **Repository Pattern**: Clean data layer abstraction
- **Component-driven Design**: Reusable UI components with Radix UI and Tailwind CSS

## Technology Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI primitives
- **Icons**: Lucide React
- **Development**: ESLint, PostCSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start learning!

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## Learning Path

1. **Start with Code Explorer** - Get familiar with the repository structure
2. **Follow Tutorials** - Learn key concepts step-by-step
3. **Explore Architecture** - Understand the system design
4. **Test Knowledge** - Take quizzes to reinforce learning
5. **Use Search** - Find specific information quickly
